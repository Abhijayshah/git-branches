🎓 Interactive Teacher Lessons

Learn core Git mental models step-by-step with interactive simulations and visual execution.

01

Feature Branch Development Cycle

Essential

Learn why developers never work directly on main in production projects (like Dr Heal). Practice branching, making isolated commits, and merging.

git checkout -b feature/patient-booking
git commit -m "add slot selector"
git checkout main && git merge feature/patient-booking
02

Understanding 3-Way Merges & Conflicts

Intermediate

When both main and a feature branch have new commits after splitting, Git performs a 3-way merge. Learn how conflict markers (`<<<<<<<`, `=======`, `>>>>>>>`) work.

Simulates concurrent commits on both main and feature
Executes git merge feature
Shows merge commit creation with 2 parent commits
03

Git Rebase: Clean & Linear Commit History

Advanced

Unlike git merge which creates a merge commit, git rebase main re-applies your feature commits on top of main for a clean linear commit graph.

git checkout feature/search
git rebase main
Moves feature branch base onto current main HEAD
04

Git Stash: Saving Uncommitted Work

Essential

Need to switch branches urgently to fix a bug without committing unfinished work? Use git stash to save work-in-progress, then git stash pop later!

git stash (stores dirty changes in stack)
git switch main (do hotfix work)
git switch feature && git stash pop
05

Git Cherry-Pick: Select Specific Commits

Advanced

Want to pick just ONE specific commit from another branch without merging the entire branch? git cherry-pick <hash> copies that exact commit over!

Find commit hash on feature branch (e.g. c418d2e)
git switch main
git cherry-pick c418d2e
06

Undoing Mistakes: Reset vs Revert

Intermediate

Learn the difference between git reset (rewinds history locally) and git revert (creates a new inverse commit safely for shared remote branches).

git reset --hard HEAD~1 (removes last commit)
git revert HEAD (safely undoes latest commit)
